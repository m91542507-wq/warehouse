# Склад эсеби / Учёт склада

Статикалык сайт (GitHub Pages). Эки режим:

- **Локалдык** (демейки): маалымат ар бир браузерде өзүнчө сакталат. Биринчи кирүү: `admin` / `admin123`.
- **Жалпы база** (Supabase): бардык колдонуучулар бир базаны көрөт.

Тилдер: Русский / Кыргызча (жогорудагы тандоо). Жарык жана караңгы тема автоматтык.

## Supabase туташтыруу (акысыз)

1. https://supabase.com → Sign up → **New project** (аты, база паролу, регион).
2. Сол менюдан **SQL Editor** → **New query** → `schema.sql` ичиндегини толугу менен коюп **Run**.
3. **Authentication** → **Providers** → **Email** → **Confirm email** өчүрүңүз (болбосо катталгандан кийин почтадан ырастоо керек).
4. **Project Settings** → **API** (же **Connect**) бөлүмүнөн **Project URL** жана **anon / publishable key** көчүрүңүз.
5. GitHub'та `config.js` файлын ачып (карандаш белгиси ✎), URL жана key маанилерин тырмакчанын ичине жазыңыз → **Commit changes**.
6. Сайтты ачып, **Регистрация** аркылуу катталыңыз. **Биринчи катталган колдонуучу автоматтык түрдө админ болот.** Калгандары «Менеджер» болуп катталат, ролду админ «Пользователи» бөлүмүнөн өзгөртөт.

Ролдор: Админ — баары; Кладовщик — товар, киреше, чыгаша; Менеджер — көрүү жана отчёттор.

> Локалдык режимдеги маалымат Supabase'ке автоматтык көчпөйт.
